# Live Q&A Tracker

A beginner-friendly Live Question & Answer Tracker built with Next.js, React and Tailwind CSS.

## Features

- Submit questions
- Display questions
- Vote for questions
- Filter pending and answered questions
- Responsive interface
- Ready for Supabase integration
- Ready for GitHub and Vercel deployment

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000
